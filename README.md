# 🌐 Exploradores de Redes

Aplicación educativa interactiva para la enseñanza de Redes de Computadoras dirigida a estudiantes de 11.º Bachillerato en Informática.

## 📚 Descripción

"Exploradores de Redes" es una microactividad educativa desarrollada para fortalecer el aprendizaje de:

- Redes LAN
- Redes MAN
- Redes WAN
- Router
- Switch
- Módem
- Punto de Acceso
- Ciberseguridad básica

La aplicación incorpora actividades de aprendizaje, repaso, autoevaluación y evaluación final.

## 🎯 Características

- Diseño responsivo
- Síntesis de voz en español e inglés
- Repaso gamificado
- Autoevaluación
- Reto final de 20 preguntas
- Sistema de puntuación
- Insignias de logro
- Certificado PDF automático
- Efectos visuales

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- SpeechSynthesis API
- jsPDF
- Canvas Confetti
- Google Fonts

## 🚀 Cómo ejecutar

1. Descarga el proyecto.
2. Abre el archivo `index.html` en cualquier navegador moderno.
3. Escribe el nombre del estudiante.
4. Completa las actividades.

## 🌍 Publicación en GitHub Pages

1. Sube los archivos al repositorio.
2. Ve a **Settings → Pages**.
3. Selecciona:
   - **Source:** Deploy from a branch
   - **Branch:** main
   - **Folder:** /(root)
4. Guarda los cambios.

GitHub generará automáticamente un enlace público para la aplicación.
